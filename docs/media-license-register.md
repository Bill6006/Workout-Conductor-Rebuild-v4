# Media license register

Every demonstration asset shipped with Workout Conductor is listed here with its source and
license before it is committed. The manifest in `src/catalog/media/mediaManifest.ts` carries the
same `source` and `license` fields at runtime. Assets that are not in this register do not ship.

## Rules

- Only original media created for this project, properly licensed media that permits
  redistribution in a public GitHub repository and GitHub Pages site, or public-domain media with
  verified terms.
- No scraping or hotlinking from Fitbod, YouTube, Instagram, TikTok, exercise websites, or other
  commercial apps. No copied branding, watermarks, or coaching footage.
- User-owned custom media (`CustomMediaSchema`) is stored only in the user's browser and backups;
  it is never committed and is kept separate from the licensed production set.
- Every production-enabled exercise must have a working poster and demonstration loop. The
  catalog test suite enforces that each production-enabled exercise resolves to a registered
  asset whose files exist.

## Development placeholders (Phase 2)

| Asset id                              | Files                                                           | Source                                                                 | License                              |
| ------------------------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------ |
| `placeholder-<movement-pattern>` (22) | `public/media/placeholders/<pattern>.svg`, `<pattern>-loop.svg` | Original diagram generated by `scripts/generate-placeholder-media.mjs` | MIT (project license), original work |

The 22 movement patterns are: horizontal-push, incline-push, vertical-push, horizontal-pull,
vertical-pull, squat, hinge, lunge, hip-extension, knee-extension, knee-flexion, calf-raise,
elbow-flexion, elbow-extension, shoulder-abduction, chest-fly, rear-delt-fly, shrug,
core-anti-extension, core-flexion, core-anti-rotation, carry.

Placeholders are labeled "PLACEHOLDER" inside the image. No exercise is production-enabled while
it resolves to a placeholder.

## Production loops (Phase 8)

Added when the production media set is created. Each row must name the exercise ids it covers,
the files, the author or source, the license, and any attribution text required by that license.

## Your own demonstration (user media)

- Tap the demonstration on an exercise card to open its details, then tap the demonstration
  again (or the "Your GIF" button) to pick a GIF, photo, or short video from the phone, up to
  3 MB. It replaces the placeholder on the card and in the details, with Replace and Remove
  under it.
- User media is stored inline in the on-device database (`customMedia`, one per exercise),
  travels with a full backup, and is never uploaded anywhere or committed to this repository.
- The card thumbnail plays the same loop as the details (the placeholder loop or the user's
  file); phones set to reduce motion get the still poster instead.
