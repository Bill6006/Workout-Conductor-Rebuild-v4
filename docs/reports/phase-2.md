## Delivered

- **Structured exercise catalog** (83 exercises) authored through `defineExercise` and validated
  by `ExerciseSchema`: id, name, aliases, primary and secondary muscles, movement pattern,
  compound / unilateral, strength and hypertrophy suitability, default training role, equipment
  requirement groups (any-of / all-of, bodyweight allowed), location suitability, setup time,
  transition cost, station, rep ranges per role, drop-set safety, superset friendliness,
  stability and grip demand, joint stress, limitation flags, substitutions, original
  instructions (setup, execution, breathing, common mistakes), difficulty, progression family,
  warm-up ramp, load type and bar weight for Plate Math, media id, production flag.
- **Muscle model** (18 muscles in 6 groups), **movement patterns** (22), and the **equipment
  model** extended from Phase 1.
- **Limitation and joint-stress tags** mapped to the profile's choices (barbell squats, overhead,
  behind-neck, dips, wide grip, knee, lower back, and any painful joint).
- **Progression families** for continuity across substitutions.
- **Conflict engine** (`src/engine/conflicts`): exercise fit, whole-selection conflicts
  (duplicates, pattern overlap, junk volume, recovery, joint stress, competing strength roles,
  time budget), and superset-pair checks (priority lifts, two demanding compounds, grip, station,
  transitions, joint stress, shared primary muscle). See `docs/conflict-engine.md`.
- **Alternative-ranking foundation** (`src/engine/alternatives`): conflict-filtered candidates
  scored on muscle overlap, pattern, role, stimulus, progression family, listed substitutions,
  preference, familiarity, setup time, overlap with the rest of the workout, joint stress, drop-set
  and superset compatibility; each carries a score, primary reason, key difference, equipment,
  setup time, progression continuity, superset impact, and warnings. Empty lists say why.
- **Production-media manifest and licensing register**: `src/catalog/media/mediaManifest.ts`
  carries source and license per asset; `docs/media-license-register.md` lists the 44 original
  placeholder diagrams (poster + SMIL loop per pattern, generated by
  `scripts/generate-placeholder-media.mjs`). No exercise is production-enabled while it resolves to
  a placeholder; tests enforce the rule.
- **Custom exercise, custom instruction, and custom-media schemas** with `customToCatalogExercise`
  so user content goes through the same engines. IndexedDB moved to version 2 with three new
  stores (upgrade test proves version-1 data survives); backups include the new arrays and Phase 1
  backups still import.
- **Warm-up, drop-set, superset, and Plate Math metadata** on every exercise.
- **Visible on the phone**: an Exercise library (search, muscle-group filter, "Not here" badge for
  what the current place cannot do, detail sheet with the demonstration, instructions, traits, and
  ranked alternatives, prefer / dislike with verified saves); Today's demo now draws from the
  catalog, passes through the conflict engine, shows thumbnails, and opens the same detail sheet
  with alternatives ranked against the rest of the demo.

## Decisions and notes

- Placeholder demonstrations are original SVG diagrams labeled "PLACEHOLDER" inside the image,
  animated with SMIL so they loop in an `<img>` with no script. Reduced-motion users get the
  poster until they press Play. Production loops arrive in Phase 8 with their own register rows.
- The demo workout remains synthetic and says so. It now uses the catalog and the conflict engine,
  but no weekly volume, progression, or time fitting. When two picks score equally it prefers the
  one with less joint stress.
- Custom media is stored as a size-capped data URL so it survives backup and restore exactly and
  never mixes with licensed production media.
- The catalog test forbids a name or alias pointing at two exercises, so stored preference names
  resolve unambiguously.
- Found while testing on Pixel 7 emulation: `overflow: hidden` on the demonstration figure made it
  a programmatic scroll container, so scroll-into-view scrolled the figure's own content and the
  Pause button drifted under other elements. `overflow: clip` fixes it; the sheet's focus effect
  now runs only on open/close.
